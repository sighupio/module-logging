# Logging Core Module Release vTBD

Welcome to the latest release of the `logging` module of [`SIGHUP Distribution`](https://github.com/sighupio/distribution) maintained by team SIGHUP by ReeVo.

This release fixes the collection of the SSH logs from the nodes.

## Bug Fixes 🐞

- [[#235](https://github.com/sighupio/module-logging/pull/235)] SSH logs are now collected on all the supported operating systems. Before, only Debian and Ubuntu nodes sent them.
